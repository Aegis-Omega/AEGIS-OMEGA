# Agent-Provenance Investigation

This directory separates three questions that must not be conflated:

1. Did an AEGIS Ω agent gather and synthesize public knowledge?
2. Did an external system reuse or derive from AEGIS Ω artifacts?
3. Is an external/internal agent the same persistent agent identity?

Question 1 can be established from signed execution lineage plus source chronology.
Questions 2 and 3 require high-specificity temporal, structural, byte-level, telemetry, or access-path evidence.

Current baseline documents prove the agent research/synthesis function and the public existence of internal memory-bearing agent deployments. They do not yet prove unauthorized transfer, rebranding, or cross-provider identity.
