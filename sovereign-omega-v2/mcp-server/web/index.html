What this proves — and what it does not

This is the self-hosted MCP + web-simulator route for the Alexa+ hackathon track. It is not an Alexa+ runtime, voice integration, or Amazon-hosted service. The demo reads a local policy file, then observes a denied model-call request. It does not call a model, spend AWS credits, or admit a repository change.

The displayed result is a local observation, not a signed third-party attestation. The exported trace includes its SHA-256; the reproducible test suite independently checks the same boundary with a zero-request bridge canary.
