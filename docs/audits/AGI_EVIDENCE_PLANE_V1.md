# Universal Intelligence Evidence Plane V1

Status: EMPIRICAL EVALUATION / ZERO AUTHORITY WEIGHT

The plane measures whether the integrated resident system improves over its strongest bound constituent baseline on six frozen axes:

- transfer;
- cross-domain generality;
- agency;
- long-horizon reliability;
- safe adaptation;
- metacognitive calibration.

A reproducibly bound improvement is `T1_EMPIRICAL`. Equal-or-worse performance is `T3_REFUTED`. Model output starts at `T2_HYPOTHESIS`. Formal theorem authority is outside this evaluator and cannot be self-asserted by an empirical observation.

Hard invariants:

`Evaluation != Authority`

`BenchmarkScore != ExecutionPermission`

`CollectiveAgreement != EffectTruth`

`SelfImprovement != SelfAuthorization`

`AGI_PROVEN` is intentionally not a state emitted by this module.

The evaluator may contribute evidence to a later capability assessment, but it has no API for issuing DecisionReceipt, ExecutionReceipt, EffectReceipt, CompleteVerification, or AtomicAdmission artifacts.
