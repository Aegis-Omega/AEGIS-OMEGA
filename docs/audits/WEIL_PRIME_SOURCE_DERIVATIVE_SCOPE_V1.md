# Weil Prime-Source Derivative Scope V1

Status: RED-FIRST / FORMAL_MATH_EVIDENCE_ONLY

Target theorem surface: constructive CoRN IR differentiation of the reusable scaled single-frequency source `a * sin(kappa * x)`.

Intended specialization after theorem admission:

- `a = alpha / pi`
- `kappa = 2 * pi * omega`
- hence the expected pointwise derivative kernel is `2 * alpha * omega * cos(2 * pi * omega * x)` after a separate constructive algebraic normalization step.

For the prime-source term used by the finite Guinand–Weil dictionary, the intended later substitution is `alpha = -Lambda(q)/sqrt(q)` and `omega = 1 - log(q)/L`.

This scope document is not a proof. It does not establish CoRN-to-O0 trigonometric transport, prime-power arithmetic semantics, a finite weighted source sum, the explicit formula, global Weil positivity, or RH.
