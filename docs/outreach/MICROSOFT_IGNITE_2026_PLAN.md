## Ignite-ready demo

The demo must fit into 90 seconds.

### Case A — Allowed

- agent identity valid;
- capability valid;
- task delegation valid;
- state fresh;
- action admitted;
- receipt emitted;
- verifier replay succeeds.

### Case B — Denied despite valid identity

- same identity;
- same broad capability;
- task authority expired OR target state changed;
- action denied before side effect;
- receipt explains exact failed gate.

The second case is the pitch.
