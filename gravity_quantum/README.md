# AEGIS Ω — Gravity–Quantum Interface Lane v1

**Purpose:** represent quantum/gravity experiments without allowing an observed quantum signal to acquire more epistemic authority than the experiment actually supports.

**Primary seed:** Dobkowski et al., *Observation of the quantum phase of free fall and the consistency with the equivalence principle*, Science Advances 12(36), 2 Sep 2026, DOI `10.1126/sciadv.aec8045`.

## Evidence DAG

`PRIMARY_SOURCE → EXPERIMENT_SCOPE → OBSERVATION → MODEL_CONSISTENCY → INTERPRETATION_DEBATE → OPEN_BOUNDARY → CLAIM_DISPOSITION`

The critical non-equivalence is:

`measurement receipt ≠ unique theoretical interpretation ≠ quantum-gravity proof`

The lane imports the existing `verifiable.chain.LineageChain`; no new trust primitive is introduced.

### Admitted in v1

- `OBSERVED`: reported relative matter-wave phase consistent with the predicted free-fall phase in the tested apparatus.
- `SUPPORTED`: the reported result is consistent with applying the equivalence principle in the authors' low-energy quantum regime.
- `INTERPRETATION_DEBATE`: a 2025 technical comment and author reply disagree over gravitational vs magnetic-recoil interpretation of the QGI phase.

### Fail-closed boundary

The following are deterministically `DENY / NOT_TESTED / authority_effect=NONE` for this experiment:

- `quantum_gravity_proven`
- `gravity_quantized`
- `gravitational_field_superposition_observed`
- `qm_gr_unified`

An unknown claim is `DENY / OPEN`; an unknown evidence status is `DENY / NOT_TESTED`.

## Determinism rules

All hash-bound records contain only strings, integers, booleans, lists and dictionaries. Floats are forbidden by the existing AEGIS verifiable envelope. Future experimental numerical data must therefore use explicit scaled integer units, e.g. `phase_microrad: 1234`, `time_ns: 2400000`, plus explicit unit metadata.

## Acceptance criteria

1. Deterministic terminal hash across replay.
2. Tamper localization at the altered stage.
3. DOI/date/source identity bound in the chain.
4. Observation and interpretation remain separate stages.
5. Low-energy equivalence-principle consistency can be admitted only as `SUPPORTED`.
6. Quantum-gravity promotion is rejected even when `OBSERVED` and `SUPPORTED` evidence exists.
7. No float in hash-bound state.
8. No hand-edit to `INTEGRATION_LEDGER.md`; exact-head ledger must be generated by the existing workflow after repository integration.
